# JDAD Recorder · Windows 团队预览版

Windows 11 x64（Intel / AMD）。此目录是独立的 Windows 实现，不改变 Mac 工程。

## 功能

- 录制整个屏幕、应用窗口或框选区域；三秒倒计时；默认无声，可单独开启麦克风。
- 从系统托盘停止录制，录制后直接进入编辑。
- 根据鼠标点击自动生成聚焦；画面中拖动聚焦框调整位置；拖动聚焦条两端调整时长。
- 在播放位置分割片段、拖动片段重新排序、按片段边界吸附、保留或删除选区。
- 撤销/重做，自动保存，本地作品库，导入视频。
- 导出 MP4（有音轨时保留声音）或无声 GIF；支持仅导出选区、取消导出。
- 左下角“发现更多应用与功能”打开 https://jdauto.joyapp.jd.com/ 。

## 使用

安装包生成在 `release` 目录。安装后选录制来源，按需框选区域和开启麦克风，点击“开始录制”。从系统托盘选择“停止录制”，然后剪辑、导出。工程保存在系统“视频”目录下的 `JDAD Recorder` 文件夹，每个 `.jdadrec` 文件夹包含工程数据和原视频；分享成片时直接发送 MP4/GIF。

工程原素材不会被裁剪删除。关闭窗口、切换作品前会等待保存；录制时关闭主窗口会保留托盘录制。意外中断后，使用“打开工程”选择带 `recording.inprogress` 的工程文件夹，可尝试恢复已有录制数据。损坏或尚未写入磁盘的录制无法保证恢复。

本版不包含系统声音、云上传、字幕、摄像头画中画；不承诺与 Mac 版工程格式互通。选择应用窗口时保持其可见，最小化窗口可能停止更新画面。

## 开发与构建

需要 Node.js 22.12+，推荐 Windows 11 x64 本机执行：

```sh
npm ci
npm run media:fetch
npm run typecheck
npm test
npm start
npm run package:win
```

媒体获取脚本下载固定版本的视频工具并校验文件；详见 `THIRD-PARTY-MEDIA.md`。`package:win` 生成 NSIS 安装包和便携 ZIP；代码签名尚未配置。Windows x64 原生鼠标与坐标组件随包提供。

开发环境可在 Mac 上检查界面、编辑和导出；真实 Windows 屏幕捕获、鼠标坐标、多屏缩放、麦克风及安装流程必须在 Windows 实机验收。具体实测记录见 `VALIDATION.md`。
