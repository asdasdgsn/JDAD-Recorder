# Mac 团队功能演示录屏工具：第一版设计

日期：2026-09-22。状态：功能范围已确认；本设计文档待审阅。暂用项目名 Demo Recorder。

## 1. 目标与已确认需求

为主要使用 Mac 的团队制作功能演示视频，优先缩短录制、简单剪辑和分享所需时间。用户已确认屏幕/窗口录制、可选麦克风、首尾裁剪与中间片段删除、自动放大鼠标操作区域、可调整缩放，以及 MP4/GIF 文件导出。Windows 后续考虑。

第一版成功标准：成员能完成“选择窗口 → 录制操作 → 自动生成聚焦效果 → 删除多余片段 → 导出并发送文件”，不需要逐帧制作动画。原始录屏保持不变，关闭后可以重新打开工程继续编辑。

## 2. 方案选择与暂定条件

采用原生 macOS 应用，SwiftUI/AppKit 构建界面，ScreenCaptureKit 负责采集，AVFoundation 负责媒体编辑和视频导出，ImageIO 编码 GIF。首版暂定 macOS 15+，优先在当前 Apple Silicon 机器验证；Intel Mac 不承诺未经验证的兼容性。

备选方案：跨平台桌面框架有利于未来复用编辑界面，但鼠标记录和系统录屏仍需原生集成；浏览器方案便于访问，但不足以满足桌面窗口外的完整鼠标跟踪需求。本版选择原生实现，优先把 Mac 的完整工作流做可靠。

分享通过本地文件完成。暂不建设账号、云存储、链接观看、团队权限或评论服务；暂不包含系统声音、摄像头、字幕、背景装饰、多轨编辑、录制暂停和 Windows 客户端。团队分发用的签名与公证另列交付条件，不把本机运行成功等同于团队可安装。

## 3. 界面与主要流程

### 录制入口

中文界面，显示最近工程、新建录制、打开工程。新建录制可选择显示器或窗口、开启麦克风并选择设备。首次操作在需要时请求系统权限，未授权时显示具体原因及设置入口。开始前倒计时 3 秒；录制期间显示时长和明确的停止按钮，菜单栏提供停止入口。屏幕录制尽量排除应用自己的控制界面。

### 编辑器

中央为视频预览；底部为可缩放时间轴、播放头与选区；侧边栏编辑所选聚焦片段。基础操作包括播放/暂停、拖动定位、保留选区、删除选区、撤销/重做。时间轴分别展示保留的视频区间和缩放片段，禁止产生空工程导出。

停止录制后先确保原始文件完成写入，再打开工程并生成自动聚焦。用户可以关闭所有自动聚焦，或逐段更改中心、倍率与时长、删除或新增聚焦片段。重新生成自动聚焦不得悄悄覆盖手动修改，需明确提示并允许取消。

### 导出

选择 MP4 或 GIF、尺寸和保存位置，显示进度、取消与完成后的“在访达中显示”。写入临时文件，成功后移动到目标；失败或取消保留工程，清理本次临时文件。覆盖已有文件使用系统保存面板确认。

## 4. 录制与鼠标坐标

默认 30 fps，目标长边最多 3840 像素且不放大原始源。通过 ScreenCaptureKit 输出采集帧，使用媒体时间戳和 AVAssetWriter 写入原始视频；可选麦克风与视频在同一时基下对齐。没有开启麦克风时不创建无意义的音轨。

鼠标位置和左/右点击使用系统事件监听加位置采样，位置采样目标 60 Hz。只保存位置、点击类型、时间和坐标映射信息，不记录键盘文字。监听随录制启动和停止，在启动失败和异常结束时也必须清理。

时间以单调时钟记录，并映射至首个有效采集帧的媒体时间。采集前后的事件不进入工程。屏幕坐标点、显示器原点、Retina 缩放和画面像素分别处理：先转换为录制内容局部坐标，再保存为 0～1 的归一化坐标。多显示器允许负原点，录制范围外的事件不触发缩放。

窗口录制保存随时间变化的窗口边界/内容映射。窗口移动后重新定位鼠标，尺寸变化保持输出画布大小与比例，必要时留边；映射暂时不可靠时跳过自动聚焦触发，不能使用过期坐标。窗口关闭或源丢失时停止并尝试保留已录内容，给出可理解的提示。

## 5. 自动聚焦规则

本版使用可解释的鼠标事件规则，不依赖联网或图像模型理解按钮。

- 点击为主要触发点，默认倍率 1.8 倍；编辑范围 1.0～3.0 倍。
- 默认提前 0.25 秒开始放大，0.35 秒进入，点击后保持约 1.2 秒，再用 0.45 秒还原；边界处截断至有效视频时长。
- 相邻点击间隔不超过 1.5 秒时合并为同一聚焦片段，延长停留，必要时平滑移动中心，避免重复拉远拉近。
- 指针在视口中央 60% 安全区域内移动时不移动镜头；超出时平滑跟随，避免微小抖动。
- 聚焦矩形始终约束在源画面内，边缘点击通过移动中心保持可见，不露黑边。
- 指针单纯经过某处不触发新的缩放。没有点击的视频保持原始画面，仍允许手动添加聚焦。
- 动画使用连续的平滑插值。同一时间只有一个最终镜头状态，自动区间重叠时合并，手动编辑校验冲突。

原始视频保留系统鼠标画面，首版不另画重复鼠标，不做鼠标外观替换。缩放会同时放大原有鼠标。

## 6. 剪辑时间与渲染一致性

工程保存源时间上的保留区间，删除片段只修改编辑决策。统一的时间映射模块将成片时间转换为源时间；鼠标轨迹和聚焦效果都通过此映射访问。硬切点直接切换镜头状态，不跨越被删内容插值。裁剪后保留片段开头可处于已放大的状态，保持源片段效果。

Preview 和 Export 共用 CameraEvaluator 与视频合成器，以同一时间输入获得相同裁剪矩形。MP4 通过 AVFoundation 合成和编码；GIF 从同一合成结果逐帧取样、缩小并编码，不另外重写一套动画。音频按相同区间裁剪并拼接，只允许必要的短淡入淡出避免切点爆音，不改变视频时长。

## 7. 导出规格

MP4：H.264 视频、有麦克风时使用 AAC 音频；30 fps；提供 720p、1080p 与原始尺寸。保留源比例，尺寸为偶数，不拉伸画面，不默认放大低分辨率素材。

GIF：无声音、循环播放；长边 640/960/1280 像素，10/15/20 fps，默认 960 像素与 15 fps。长片段提示文件可能较大，并允许继续或缩短选区，不声称预估体积精确。默认导出完整剪辑，也可明确选择当前选区。长任务使用受限缓存或分批帧处理，不把所有高分辨率帧加载到内存。

## 8. 工程与模块边界

每个本地工程为文件包：`project.json` 保存版本、素材引用、保留区间、聚焦片段、导出偏好；`media/` 保存原始素材；`events.json` 保存鼠标事件与坐标映射；`thumbnails/` 保存可重建缓存。采用工程内相对路径，移动工程后仍可打开。

- CaptureService：源选择、权限状态、视频/麦克风生命周期。
- PointerRecorder：事件采样、时间对齐和范围过滤。
- ProjectStore：原子保存、版本检查、工程读取、异常恢复标记。
- EditTimeline：保留区间、时间映射、撤销/重做。
- AutoZoomPlanner：鼠标事件到可编辑聚焦区间。
- CameraEvaluator：任意源时间的最终镜头参数。
- MediaRenderer：预览与导出的统一合成逻辑。
- ExportService：编码、进度、取消和目标文件管理。

状态流为 idle → preparing → recording → stopping → editing → exporting；失败回到可恢复状态。导出期间保持当前工程编辑版本快照，避免输出混入后续修改。编辑变更自动保存；写入使用临时文件替换，坏文件不覆盖最后有效工程。

## 9. 异常处理

区分录屏未授权、麦克风未授权、事件采集不可用、源丢失、磁盘空间不足、工程素材缺失和编码失败。录屏权限不足不能假装开始；麦克风失败时明确提供无声录制选项；轨迹不可用时明确说明自动聚焦不可用，仍允许原画录制和手动聚焦。

启动时发现未正常结束的工程，检查媒体可读性。可恢复就保留并打开，无法恢复就说明受影响的素材；不承诺系统崩溃后的所有录制都可恢复。

## 10. 验收与验证

自动化验证：时间区间删除和拼接、撤销重做、时间映射、坐标转换（含 Retina/负原点）、点击合并、边缘聚焦约束、插值连续性、工程保存重开与版本拒绝、导出取消清理。测试针对行为和边界，避免只复述实现。

媒体集成验证：生成含移动目标和已知音频节拍的固定素材，执行中间删除和缩放，实际导出 MP4/GIF 并重新解码检查尺寸、时长和代表帧；MP4 音画同步误差目标不超过 100 ms，视频时长允许一帧量化误差，GIF 允许一帧 GIF 采样误差。预览和导出代表帧的聚焦区域应一致。

真实 Mac 人工验收：屏幕与窗口录制、可选麦克风、第一次授权/拒绝、录制后恢复、窗口移动与改尺寸、多显示器、边缘点击、快速连续点击、无点击片段、10 分钟录制、文件导出取消与重试、工程重开。没有真实验证的项目在交付报告中明确列出。

第一阶段交付包含源代码、可在本机运行的应用、使用说明和验证记录。团队顺畅安装需要 Developer ID 签名、公证及团队机器验证；使用者未提供相关身份前只能交付本地测试构建，不声称已完成正式分发。
