# JDAD Recorder

用于团队功能演示的轻量录屏与剪辑工具。录下屏幕操作，自动放大鼠标点击区域，再通过简单剪辑导出 MP4 或 GIF。

项目包含两个独立实现：**Mac 原生版 0.4.4** 和 **Windows 团队预览版 0.1.0**。录制素材与编辑记录保存在本机，应用不提供云端上传功能。

## 主要功能

- **快速录制**：选择屏幕、应用窗口或框选区域，倒计时后开始；麦克风可选，默认关闭。
- **缩略图选来源**：查看屏幕和窗口的预览卡片，点击选中；Mac 可手动刷新预览。
- **自动聚焦**：根据鼠标点击生成放大片段，突出正在演示的操作区域。
- **可视化聚焦编辑**：在原画面中拖动聚焦框，调整位置和倍率；拖动聚焦时间条两端改变持续时间。
- **时间轴剪辑**：手动分割、拖动片段排序、吸附对齐、保留或删除选区、撤销与重做。
- **导出分享**：导出整个作品或当前选区为 MP4 / GIF；GIF 无声音。
- **本地工程**：原始视频与剪辑记录分开保存，编辑自动保存，支持打开工程和导入视频。
- **更多应用入口**：左下角“发现更多应用与功能”打开 [京东汽车应用与功能入口](https://jdauto.joyapp.jd.com/)。

Mac 0.4.4 新增顶部居中的悬浮停止按钮，显示录制时长；切换到演示应用后仍可使用。Windows 当前通过托盘停止录制，尚未同步这个悬浮按钮。

## 安装与首次使用

源码仓库不包含安装包、依赖目录或视频素材。维护者从下文的构建输出中分发安装包；仅克隆仓库不会得到可直接运行的安装文件。

### Mac

1. 打开 `JDAD-Recorder-0.4.4-Mac-arm64.dmg`，将 `JDAD Recorder.app` 拖入“应用程序”。升级前退出旧版，避免同时运行多个版本。
2. 在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”（不同系统版本名称可能略有差异）中允许 JDAD Recorder。历史权限条目可能仍显示 Demo Recorder。
3. 需要讲解声音时再开启“录制麦克风”并授权；无声录制不需要麦克风权限。

当前 Mac 构建采用 **Apple Development 证书签名**，不是临时 ad-hoc 签名；尚未完成 Developer ID 分发签名及 Apple 公证。其他 Mac 的安装运行仍需验收，请勿关闭系统安全保护来绕过安装拦截。

### Windows

运行 `JDAD-Recorder-0.1.0-Windows-x64.exe`，或将便携 ZIP 完整解压后启动 `JDAD Recorder.exe`。便携版需要保留同目录中的组件文件。

当前安装包尚未配置 Windows 代码签名，也尚未在 Windows 实机完成录屏与安装运行验收。详见 [Windows 使用说明](windows/README.md)。

## 录制与剪辑流程

1. 打开录制页面，点击来源缩略图选择屏幕或窗口。需要局部画面时切换“指定区域”，拖动框选并确认。
2. 按需开启麦克风，点击“开始录制”。倒计时后切换到要演示的应用。
3. Mac 点击屏幕顶部的“停止录制”或菜单栏入口；Windows 从系统托盘选择“停止录制”。保存完成后进入编辑器。
4. 定位播放头，点击“分割”：Mac 快捷键为 `⌘B`，Windows 为 `Ctrl+B`。拖动片段可调整顺序，片段连续排列；音频和聚焦效果跟随素材片段。
5. 拖动选区手柄，使用“仅保留选区”或“删除选区”裁剪。拖动聚焦条两端调整时长，打开聚焦位置编辑器修改画面重点。
6. 点击导出，选择 MP4 或 GIF、尺寸和保存位置。只需要一部分内容时选择仅导出选区。

Mac 的聚焦设置时间使用原始素材秒数，剪辑选区使用成片秒数。MP4 为 H.264 视频，有录制音轨时保留声音；GIF 循环播放且无声。两平台具体导出选项可能不同。

## 工程保存与恢复

| 平台 | 默认位置 | 工程格式 |
| --- | --- | --- |
| Mac | `~/Movies/Demo Recorder/` | `.demorec` 文件包 |
| Windows | 系统“视频”目录下的 `JDAD Recorder` | `.jdadrec` 文件夹 |

请移动或备份整个工程，不要单独移走内部视频。Mac 更名后保留旧保存目录与应用标识，以延续已有工程和权限识别。两平台工程格式目前**不承诺互通**，跨平台分享建议使用 MP4 / GIF。

异常退出后，可尝试打开未完成的工程恢复可读取素材。恢复能力取决于视频是否已写入磁盘，不保证找回损坏或尚未写入的数据。导入视频不含本应用采集的鼠标轨迹，因此需手动添加聚焦。

## 从源码开发

### Mac 原生版

需要 macOS 15+、Xcode / Swift 6 工具链。项目使用 Swift 5 语言兼容模式，无第三方运行时依赖。

```sh
# 在仓库根目录执行
swift test
swift build

# 生成带证书签名的应用
DEMO_OUTPUT_DIR="$PWD/dist/v0.4.4" ./scripts/build-app.sh

# 制作并校验 DMG
./scripts/package-dmg.sh "$PWD/dist/v0.4.4/JDAD Recorder.app"
```

应用打包需要钥匙串中有效的 Apple Development 或 Developer ID Application 签名身份。只有一个可用身份时自动选择；多个身份时通过 `DEMO_SIGNING_IDENTITY` 指定证书名称或指纹。证书和私钥不应提交到仓库。

脚本拒绝临时 ad-hoc 签名，以减少更新后录屏授权失效。构建前退出相同输出目录中的应用，或使用独立输出目录。DMG 输出到根目录的 `dist/`。

### Windows 版

需要 Node.js 22.12+，推荐在 Windows 11 x64 本机执行：

```sh
cd windows
npm ci
npm run media:fetch
npm run typecheck
npm test
npm start
```

制作安装包：

```sh
# 仍在 windows 目录
npm run package:win
```

输出位于 `windows/release/`，包括 NSIS 安装包和便携 ZIP。媒体下载脚本校验上游 SHA-256；安装包构建前会核对 Windows x64 原生组件。跨平台打包成功不等于已通过 Windows 运行验收。

更多细节见 [Windows README](windows/README.md) 和 [媒体组件来源与许可](windows/THIRD-PARTY-MEDIA.md)。

## 常见问题

**Mac 已开启录屏权限，仍然被拒绝？**

先确认运行的是“应用程序”里的最新版本，而不是旧构建或磁盘映像中的副本。早期临时签名版本或更换签名身份可能导致旧授权失效。退出应用，仅移除并重新添加本应用的录屏权限条目，然后重新打开；不要重置其他应用权限。

**找不到目标窗口？**

先打开目标窗口并保持可见，再刷新来源。Mac 在“指定区域”模式下只显示屏幕，需要切回“屏幕 / 窗口”模式选择窗口。

**没有自动生成聚焦？**

导入素材没有鼠标轨迹；未采集到有效点击时也不会生成自动聚焦。可手动添加聚焦，并检查鼠标相关权限与录制范围。

**为什么 Windows 包较大？**

Windows 版随包提供 Electron 和 FFmpeg/ffprobe；Mac 版使用系统媒体框架。安装包压缩体积与解压后占用空间不同。
